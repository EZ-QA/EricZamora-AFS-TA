# Playwright Automation with TypeScript


## OBJECTIVE
Demonstrate the ability to automate web interactions using Playwright + TypeScript on the following application:  
https://demoqa.com/automation-practice-form

---

## SCOPE

The following functionalities are automated:

- Web Tables — Edit values in the table, submit the form, and verify the changes are saved
- Forms — Fill and submit the student form using multiple data sets
- Widgets (Select Menu) — Select a value from each type of dropdown

---

## PROJECT STRUCTURE

- `pages/` - Page Object Model classes
- `tests/` - Test cases
- `test-data/` - Test data files
